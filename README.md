# new_portfolio
A portfolio website that showcase and display my works and it is build with react.js

## Development requirements

This project uses Vite 8 and Vitest 4, which require Node 20 or newer.

- Recommended: Node 20.x or 22.x
- Unsupported: Node 18.x

If GitHub Actions or your local environment fails on Node 18, update the runtime before running `npm install`, `npm test`, or `npm run build`.
